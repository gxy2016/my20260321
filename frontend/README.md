# 图书管理系统 - 前端

## 项目结构

```
frontend/
├── index.html      # 主页面（包含列表、录入、查询三个 Tab）
├── styles.css      # 样式文件（响应式设计）
├── app.js          # 应用逻辑（API 调用、Mock 数据、CRUD 操作）
└── README.md       # 说明文档
```

## 功能

### 1. 图书列表展示
- 卡片式展示图书信息（书名、作者、ISBN、出版社、价格、出版日期）
- 每页 10 条，分页导航
- 搜索框支持按书名/作者快速搜索
- 加载状态、空状态、错误状态处理

### 2. 录入图书
- 表单录入：书名、作者、ISBN、出版社、出版日期、价格、描述
- 表单验证（必填项检查）
- 提交后自动重置表单
- 成功/失败提示

### 3. 删除图书
- 点击删除按钮弹出确认对话框
- 确认后执行删除操作
- 删除后自动刷新列表

### 4. 高级查询
- 多条件组合查询：书名、作者、ISBN、出版社、价格区间
- 查询结果卡片展示
- 支持重置查询条件

## 技术栈

- 纯 HTML5 + CSS3 + JavaScript (ES6+)
- 无框架依赖，轻量级
- 响应式设计，适配移动端
- CSS 变量主题定制

## API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/books | 获取图书列表（支持分页、搜索） |
| GET | /api/books/{id} | 获取单本图书详情 |
| POST | /api/books | 新增图书 |
| PUT | /api/books/{id} | 更新图书信息 |
| DELETE | /api/books/{id} | 删除图书 |

## 开发说明

等 Bob 完成后端 CRUD API 后，将 `USE_MOCK` 改为 `false` 即可切换真实 API。
